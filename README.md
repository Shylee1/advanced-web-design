# Advanced Web Design Skill

Enterprise-level skill for AI agents that plan, research, and construct production websites and web apps.

## Features

- Exhaustive multi-aspect planning (narrative, flows, functions, workflows, textures, colors, shading, animations, 3D, motion, parallax, optimization, tech stack)
- Full reference to UI UX Pro Max design intelligence catalogs
- Zero-simplification design fidelity
- User-only iteration rule
- Continuous trajectory awareness
- Multi-output continuation protocol
- Sub-agent delegation support
- Growing knowledge base of trends and techniques
- Production readiness for 1 000 000 concurrent users
- Strong priority for React + React Three Fiber + Three.js + WebGL + Remotion
- Exceed-expectations additions without altering core requirements
- SEO, AEO, GEO, and full AI-agent compatibility

## Installation

Copy the `advanced-web-design` folder into your agent's skills directory (for example `.grok/skills/` or the equivalent for your platform).
